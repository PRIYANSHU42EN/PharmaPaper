# PharmaPaper

> Your Gateway to Excellence in Pharmacy Education

PharmaPaper is a high-performance, syllabus-aligned web platform providing verified lecture notes, unit summaries, and study resources for B.Pharm and D.Pharm students.

## Features
- **Syllabus-Aligned Notes**: Complete coverage for B.Pharm (Semesters 1–8) and D.Pharm (Years 1–2).
- **Unit Breakdown**: Direct access to downloadable notes and guides per unit.
- **Admin Management**: Secure content and unit notes management dashboard.
- **Progressive Web App (PWA)**: Installable on Android, iOS, and desktop with offline readiness and full app icons.

## Tech Stack
- **Framework**: Next.js (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS
- **Database & Storage**: Supabase (PostgreSQL, Public Buckets)
- **Deployment**: Vercel
