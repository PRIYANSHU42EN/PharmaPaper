### C. RLS Policies
- **Existing Migrations**:
  - `profiles`: Public select, self-insert, self-update using `auth.uid()::text = user_id`.
  - `notifications`: Manage own notifications using `auth.uid()::text = user_id`.
  - `api_logs`, `ip_blocklist`, `suspicious_activity`, `email_templates`, `platform_config`, `rate_limit_config`: Deny all public access (`USING (false)`), accessed via service role.
- **In-Spec Required Policies (from `tech.md`)**:
  - `semesters`, `subjects`, `units`, `downloads`, `posts`: Public SELECT (`USING (true)`), Authenticated Admin ALL (`USING (auth.role() = 'authenticated')`).
  - `download_logs`: Anon INSERT (`WITH CHECK (true)`), Authenticated Admin SELECT (`USING (auth.role() = 'authenticated')`).
  - `comments`: Anon INSERT (`WITH CHECK (true)`), Public SELECT approved only (`USING (approved = true)`), Authenticated Admin ALL (`USING (auth.role() = 'authenticated')`).
